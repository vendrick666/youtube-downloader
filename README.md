# YouTube Downloader

Обёртка над [yt-dlp](https://github.com/yt-dlp/yt-dlp) для Windows: видео, плейлисты и каналы с YouTube в MP4 или только звук в MP3.

## Программа с окном (exe)

Один раз дважды кликни по `build_exe.bat`: он соберёт `YouTube Downloader.exe` в эту папку и положит ярлык на рабочий стол. Для сборки нужен Python, а самому exe Python уже не нужен, так что его можно переносить на другие компьютеры.

В окне: ссылка (подставляется из буфера обмена сама), качество, фрагмент по таймкодам, папка, кнопки «Скачать», «Отмена» и «Открыть папку», прогресс со скоростью и оставшимся временем. Папка и качество запоминаются.

**Фрагмент.** Впиши начало и конец (`1:23`, `1:02:03`, можно `1.23`) и скачается только этот кусок. Пустой конец значит до конца видео, оба поля пустые значат видео целиком. Файл получает метку вроде `1m23s-2m45s` и не путается с целым видео. С галочкой «Точно по кадрам» фрагмент режется ровно по таймкодам, но перекодируется и поэтому дольше; без неё быстрее, но начало может сдвинуться на пару секунд.

Программа сама скачивает официальные yt-dlp, Deno и FFmpeg в `%LOCALAPPDATA%\YTDownloader\bin` (FFmpeg и Deno, уже скачанные spotDL, использует повторно) и раз в сутки обновляет yt-dlp. Если YouTube не отдаёт видео, она переключает yt-dlp на свежую тестовую сборку и пробует ещё раз. `cookies.txt` для неё кладётся рядом с exe. Подробный лог последнего скачивания открывает кнопка «Лог».

Windows Defender иногда с подозрением смотрит на самодельные exe, собранные PyInstaller. Если он ругнётся, нажми «Подробнее» и «Выполнить в любом случае».

## Скрипт (без сборки)

### Запуск

Двойной клик по `YouTube_Downloader.bat`, вставить ссылку и выбрать качество:

1. 1080p, MP4 (H.264): открывается везде (по умолчанию, просто Enter);
2. максимальное: до 4K/8K, MP4 с кодеком AV1/VP9, нужен VLC или свежий плеер;
3. 720p, MP4 (H.264): файл поменьше;
4. только звук, MP3 с обложкой.

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/), при установке отметить «Add python.exe to PATH»). Всё остальное скрипт ставит сам.

Можно запускать и напрямую:

```
python youtube_downloader.py "https://youtu.be/..." --quality 1 --folder "D:\Video" --section 1:23-2:45
```

### Что делает скрипт

- раз в сутки обновляет yt-dlp; Deno ставится вместе с ним (`yt-dlp[default,deno]`);
- FFmpeg берёт из системы, у spotDL (`~/.spotdl`) или сам ставит `imageio-ffmpeg`;
- одиночное видео сохраняет как `Название [id].mp4`, плейлист или канал кладёт в отдельную папку с нумерацией;
- если ссылка на видео из плейлиста (`watch?v=...&list=...`), спрашивает, качать одно видео или весь плейлист;
- спрашивает фрагмент: `1:23-2:45`, `1:23-` (до конца), `-2:45` (с начала) или Enter, чтобы скачать видео целиком; режет точно по кадрам;
- если скачать не вышло, определяет причину (бот-проверка, возрастное ограничение, сеть/DNS, 403, видео недоступно) и пишет подробности в `ytdl_debug.log`; на 403 и прочих сбоях ставит свежую тестовую сборку yt-dlp и пробует ещё раз;
- в конце показывает, какие файлы реально скачались и что нет.

### Настройки

- Папка по умолчанию задаётся в `YouTube_Downloader.bat` (`FOLDER`) и в `youtube_downloader.py` (`DEFAULT_FOLDER`).
- Если YouTube пишет «Sign in to confirm you're not a bot» или просит подтвердить возраст, положи рядом со скриптом `cookies.txt` с куки youtube.com, экспортированными из браузера. Файл подхватится автоматически.
